# No dark mode

The Portfolio ships one theme. The `.dark` block from the source tweakcn theme has been
deleted rather than left half-correct.

Recorded because every shadcn project has a dark mode and its absence will look like an
oversight. It is not. This design is made of physical objects — a paper ground, tape,
a cover image stuck on like a sticker, a photograph of Anna. Inverting it does not dim
those things, it denies them. Cantaloupe would also need re-deriving, since it carries
black type only, and the blue at L=0.51 is too dark to sit on black without a second
light variant. Half the theme work disappears with this decision.
